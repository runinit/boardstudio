# Retained keyboard example data

`tooling/demo-projects/src/demos/` contains measured layouts and TypeScript project generators used to build example `.boardstudio` files for application checks. These files are build tooling, not a separate browser frontend.

The keyboard examples are adaptations from pinned upstream PCB measurements. They preserve measured key positions and use BoardStudio's bundled Ergogen parts, electrical resolver, and outline generation. They do not reproduce the source board routing, firmware, or fabrication readiness. Source revisions, paths, checksums, and applicable licenses are recorded beside the layout data; license texts are in `licenses/`.

Sofle attribution is in [SOFLE-LICENSE](SOFLE-LICENSE). Measured layout data is in `content/layouts/sofle-layouts.json` and `keyboard-layouts.json`.

To refresh checked-in measurements from an already available upstream checkout, run:

```sh
python3 scripts/extract-sofle-layouts.py /path/to/SofleKeyboard
python3 scripts/extract-keyboard-layouts.py /path/to/checkouts
```

Add `--check` to either command to compare an extraction with the committed data
without rewriting it.

Project fixture archives are generated by the native `prepare_demo_projects` Core example as part of the normal build. The generators adapt key layouts and bundled parts; they do not import upstream footprints, routing, or executable code.
