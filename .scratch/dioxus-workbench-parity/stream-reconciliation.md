## Status vocabulary

- **Observed:** pinned React behavior or a candidate state is directly shown in retained source/browser evidence.

- **Wired:** that behavior is reachable in the actual public candidate route with authoritative state/actions.
- **Paired-verified:** the same exact fixture and relevant UI/history/durability journey passed in React and Dioxus.
