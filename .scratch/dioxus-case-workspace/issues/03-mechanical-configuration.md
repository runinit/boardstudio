# F7.4a: Configure the mechanical stack

**Parent:** F7.4 — Mechanical assembly configuration editor.

**What to build:** A designer can enable and configure the selected board's mechanical stack, choose supported construction and mount arrangements, edit the represented stack dimensions, inspect resolved layers and diagnostics, and disable the stack without losing authored Case bodies.

**Blocked by:** INT.1 only, matching F7.4's canonical `start_after`. This saved-fixture editor does not wait for F7.3's viewer or F3/F4/F5 completion.

**Parent acceptance join:** INT.2 remains required for F7.4 integrated acceptance. F7.4a is only one bounded child and cannot close the parent.

**Status:** ready-for-agent; independently reviewed and published.

- [ ] When no matching mechanical configuration exists, offer the existing “Configure mechanical stack” action with the current supported initial settings. For the selected canonical board use `SetMechanical`; for a physical-instance Case scope, apply to that instance through the existing shared-construction/instance update and normal accepted document edit path. Preserve unrelated document data, authored bodies, board/instance IDs and fields on ordinary configuration edits.
- [ ] Expose the represented construction choices only: PCB FR-4 / printed / CNC / cut-sheet method; tray / rigid / gasket mount; shell / sheet bottom; middle frame only for sheet bottom; integrated plate frame only where allowed. Choosing gasket mount performs the source-prescribed compatible state updates (including removing only `auto-closure/` generated closure mounts) and disables incompatible construction controls; do not invent choices.
- [ ] Edit plate, plate foam, PCB, bottom foam, bottom, wall, clearance and radial opening allowance dimensions. A plate-thickness change recomputes plate-to-PCB gap from the active switch family, updates same-family profile gaps, and changes plate foam only when its previous value was still the existing derived default. Selecting a switch family uses that family's default plate thickness, recomputes its gap and other switch-profile gaps, and resets plate foam to its derived default. Show derived gaps and supported-thickness range, including unresolved/missing-profile explanations; do not recalculate core geometry in the UI.
- [ ] Show the resolved stack layers in current order with derived thickness/Z and stable layer IDs; selecting a layer follows the existing Case display-selection path. Show current mechanical diagnostics/findings and route a selected finding through the existing finding navigation.
- [ ] Keep generated and authored Case modes exclusive. When the selected instance has matching mechanical configuration, keep authored Case body records saved but hide/disable their authoring controls while the generated stack is active. On canonical-board scope, explicit “Disable mechanical stack” clears only the canonical document's mechanical configuration; on physical-instance scope it clears shared construction and every instance mechanical configuration, sets every `constructionLinked` false, and leaves canonical mechanical configuration and authored body records untouched. Do not claim per-instance mechanical configuration survives instance-scope disable. For non-null instance configuration updates, replace shared construction with a copy whose local gasket supports are empty, set all instances linked, and replace only the selected instance's full mechanical configuration; retain other instances' per-instance feature data. When configuration belongs to another board, show the existing mismatch explanation and “Show configured board” action beside the selected board's authored-body editor; do not expose the mismatched configuration as editable for the current board.
- [ ] Scope every field draft, submit and feedback to the current full session/document/board/instance Scope, accepted snapshot token/revision, configuration board ID and component lifetime. Admit only when the current instance-selection guard passes, Runtime is Ready, no display preview or gesture is active, the accepted revision is Saved, and no configuration operation is already pending. Serialize commits; apply each accepted field patch to the latest matching configuration after the prior operation settles so an older full-configuration replacement cannot erase a successful edit.
- [ ] On successful operation outcome, clear a field draft only after the expected accepted revision is saved. On rejection/failure retain a correctable draft and show the current error; a busy/stale request cannot replace or settle another field's pending request. Escape restores the accepted field value; preserve the source numeric field's blur/Enter commit and Escape rollback behavior with one commit per field.
- [ ] Use existing `SetMechanical`, physical-instance configuration/update and replace-document operations, current profile/stack resolution, Runtime operation outcomes and standard Undo/Redo. No public API/schema/visibility changes, new geometry engine, duplicate state/history, or second persistence route.
- [ ] Public paired browser evidence covers configure/edit/disable; tray/rigid/gasket and sheet/frame conditional controls; valid/invalid numeric blur/Enter/Escape; coupled plate/gap/profile updates with customized plate foam preserved; derived dimensions, stack selection and diagnostics; generated mode hiding/restoring authored editing with body retention; cross-board mismatch navigation; busy/failure/stale feedback; canonical disable clearing only canonical mechanical config; multi-instance disable clearing shared and every instance mechanical config/link flag while preserving canonical mechanical config and authored bodies; non-null instance updates changing only selected per-instance settings and shared construction; Undo/Redo, actual native saved document/archive payload, save/reopen, and return after scope changes. Fixture-only form rendering does not establish F7.4 or INT.2 acceptance.

Coordinate one private configuration patch callback and avoid concurrent edits to those owners.
