## Required policy and source

Pinned React `app/src/main.tsx:24,36-37` stores an explicit instance ID and resolves it by selected board, falling back to the first matching board instance in document order. `useProjectSession.ts:72` clears that explicit preference on project open. `Workbench.tsx:597-601` changes board without clearing the explicit preference. Thus a valid explicit selection survives ordinary updates; visiting another board uses its fallback without overwriting the preference; returning or Undo restoring the preferred instance can restore it. Do not filter candidates by mechanical presence, flip, name, role or topology.

Remove that option **when matching instances exist**, retaining canonical scope naturally for boards without instances; document this intentional parity correction. Invalid explicit callback IDs are rejected, not silently replaced. A board-only route preserves the preference and resolves the target board’s effective instance. Boards without instances use None.
