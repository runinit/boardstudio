## Implementation and ownership

- `web/src/firmware_position_projection.rs` is a pure, native-testable projection of ordered matrix keys, real Core-reported supported press inputs, labels, selected-board legacy values, and plan lifecycle. The Editor UI scope is retained separately from the normalized board-plan scope.
- `web/src/presentation/pcb_wiring.rs` owns the private Wiring handoff props and preserves exact physical-instance UI scope alongside the existing normalized board plan source.
- `web/src/presentation/pcb_wiring/controller.rs` owns the root-called Editor-lifetime edit hook. It rechecks workspace, scope generation, accepted session/document/board/instance, token/revision, executor, current plan, and real plan key membership before observing and submitting the existing `SetKeyBinding` edit.
- `web/src/presentation.rs` invokes the hook unconditionally at Editor lifetime and supplies the projection/callback/feedback to PCB Wiring.
- `web/src/presentation/workspace_composition.rs` routes the private seam into the PCB inspector.
- `web/src/main.rs` includes the pure projection module in the native page test harness. This was needed because the Dioxus presentation tree is wasm-gated and nested presentation tests do not execute in the native page test binary.

After submission, exact operation settlement does not reuse admission token/plan equality. It remains observed through accepted plan refresh and hidden inspector state, waits for durable save, confirms the value from the latest accepted document, suppresses feedback when the target moved, and reports persistence failure without changing accepted values. Retry remains a fresh action with a newly admitted source. Core continues owning legacy-to-first-typed-layer synchronization.
