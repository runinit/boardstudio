- [ ] Add macros with the reference defaults (generated stable ID, `Macro N` display name, 30 ms tap, 0 ms between-action wait, one tap of key A); rename and remove by stable macro ID without retargeting remaining bindings.
- [ ] Edit each macro's name, tap duration, between-action wait, and steps in their existing sequence. Steps support tap, press, release or wait. Add step appends tap with key-press A. Changing kind to wait creates wait 100 ms; changing to tap, press or release retains that chosen kind with key-press A. The reference exposes a plain keycode field for each non-wait step; it does not expose the general F6K.2 behavior/layer/modifier/macro selectors here. Macro field edits must update only their requested field/step and leave other accepted steps and macro IDs intact. Do not add step reordering UI or a MoveStep operation. Support add/remove and do not allow the last step to be removed.

Preserve the React blur-only text/numeric commit behavior; do not claim Enter handling as parity because these inputs have no Enter handler.
