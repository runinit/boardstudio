  fixture: "reviung41-original.boardstudio" };

Here, both calls reported one intercepted `arrayBuffer` read. The public click command returned success, but at the first settled sample (~550 ms after the read began) both pages still showed Sofle. The Project menu was not visible in that sample; I did not capture a separate DOM snapshot between upload dispatch and the click. Dioxus showed the same sampled sequence in this attempt. This does not prove that a newer project selection occurred, so supersession remains unqualified; no product race defect is claimed.
