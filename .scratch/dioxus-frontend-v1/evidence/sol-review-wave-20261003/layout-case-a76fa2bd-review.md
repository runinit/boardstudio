## Spec

**Original a76 Layout findings:**

1. **P1 pointer capture cannot start from the delegated root.** `outline_lifecycle.rs:1892` casts `pointer.current_target()` to `SvgElement`. Installed exact Dioxus 0.7.10 interpreter `src/ts/core.ts:119` registers bubbling listeners on `this.root`; WebEventExt returns the raw native event. Thus currentTarget identifies the root HTML element, the cast fails and the handler exits before PointDrag/capture. Capture a validated handle target/ref and stop framework propagation. F3.4d requires “Pressing a handle captures that pointer and previews the moved point.” Author's actual native drag receipt should confirm this immediate failure.
2. **P1 final commit can be dropped while preview applies.** `OutlineAction::is_current` (`outline_lifecycle.rs:332`) requires `Lifecycle::Ready` for Preview and Commit, while application pump sets `Applying` during an active preview (`application/src/session.rs:1275`). Pointer-up removes drag/capture/local preview and dispatches its Commit synchronously (`outline_lifecycle.rs:1757–1770`); before the preview reply it is silently rejected. Preserve the captured final sample through transaction-owned preview settlement. Spec: “only its final sample may commit” and one ordinary commit on release.
3. **P1 return-to-source fails to retire the displayed preview.** `apply_point_sample` replaces `moved` with final inequality (`outline_lifecycle.rs:2040`); finish/drop issue ClearPreview only when that flag remains true (`1763`, `1696`). Moving away, submitting Preview, and returning to the original points can therefore skip both Commit and ClearPreview, leaving an old scene. Retire any transaction that published/submitted preview even when final points are unchanged; no-op release must not add history.
4. **P2 snap context drifts from the pinned algorithm.** `outline_lifecycle.rs:2002–2007` derives exclude/previous from mutable `drag.preview_points`; React `OutlineControlOverlay.tsx:34–35` uses the original feature points throughout a drag. After one sample the original source vertex stops being excluded and collinear/perpendicular guides change. Keep immutable original world points in the drag context. `outline_snapping.rs:157,162` also uses Rust `.round()` at grid ties, unlike React `Math.round` (`outlineSnapping.ts:10`): e.g. −0.5 grid unit snaps to −1 instead of 0. Spec requires the existing snap policy verbatim.
