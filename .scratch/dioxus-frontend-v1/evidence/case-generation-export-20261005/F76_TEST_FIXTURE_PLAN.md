# F7.6 required mounted tests: fixture plan

`F76_REQUIRED_TESTS.patch` is an unapplied, uncompiled review patch. It touches only test code paths in `cad_presentation.rs`, `runtime.rs`, and `presentation.rs`; it does not change production behavior or API visibility.

The shared `configured_exact_mechanical_runtime()` fixture is retained: accepted mechanical Case document, one Plate body, matching ready outline row, exact same-scope/token/revision `CadScene`, and no external assets. The fixture test model must additionally carry `Lifecycle::Ready` and `Durability::Saved { revision }`; the previous draft omitted these, which would have made the owner's legitimate readiness predicate reject the baseline.

`export_host` calls a wasm-only presentation bridge that assembles the existing contexts and invokes `use_mechanical_settings_mount`, the same owner hook used by Editor. It does not reproduce `case_generation_admission::is_ready`. The mounted baseline first asserts Export geometry enabled, so an incomplete owner fixture fails at setup rather than masquerading as the target regression. Existing contexts: Runtime root; SelectionAdapter with generation signal; Case workspace; InstanceSelection; CaseSelection; ResolvedTheme; CaseGenerationState. The mounted shared-viewer subtree receives its own contexts from `use_case_viewer_test_contexts`.

The failure test retains the old exact `CadScene`, advances only accepted token/revision in the same scope, marks the current owner Failed, checks failure text + Previous geometry + disabled export, then asserts explicit Update dispatches exactly one `StartGeneration` for that scope and current accepted owner. Live preview is paused before the transition to prevent an automatic event racing the assertion.

The draft test writes actual `ReadModel.display_preview` at the test Runtime seam, so its claim is limited to mounted readiness/admission reacting to preview state; it does not claim a Core preview worker ran. For gesture, the actual Session reducer receives `GestureBegin` and `GestureCancel`; its resulting `GestureView` is presented alongside the same exact Case fixture. The test claims Session-produced gesture state gates mounted export and cancellation restores it, not that browser pointer capture or movement ran. Both transient states assert disabled Export and no `StartExport`; cancellation/clearing restores exact readiness.

Runtime events are intercepted synchronously by the existing definition-name test fixture. Session gesture reduction is synchronous. Each Dioxus refresh uses the existing 100 ms `settle()` barrier. Mechanical settings resolution may run asynchronously after mount; no CAD generation/export worker completion is expected or claimed.
