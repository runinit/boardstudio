## P1: delayed keyboard action can be retargeted to a new selection

`web/src/presentation/objects/keycap_size.rs:90-107` retains a `use_callback` handle and reads `draft()` after the 150 ms await. The installed Dioxus 0.7 implementation explicitly replaces that handle's closure on each render. `layout_workspace.rs:103-104` keeps the component mounted across supported selection changes. The owner-change effect resets draft/sent, but does not invalidate `keyboard_generation`. Consequently an old selection's timer can call the new selection's callback with the new selection's snapshot/owner and current draft. This bypasses the controller's otherwise sound immutable-envelope rejection because the leaf manufactures a fresh envelope. A concrete damaging case is switching to a mixed-width row before the timer fires: mixed_x makes should_send true and the untouched new row is normalized to its first item's width. React `MatrixInspectorPanel.tsx:58` keys KeySizeControls by scope and `KeySizeControls.tsx` clears its timer on unmount.

Invalidate/cancel the scheduled action on owner changes and retain the event-time owner/value/source envelope (or use a proven actual keyed owner boundary). Add a mounted production regression: schedule on A, replace selection with mixed B before expiry, verify no B edit; also verify ordinary same-owner timer behavior. A static-root key alone is insufficient given the previously confirmed Dioxus release key issue.

## P2: result feedback is not qualified by its owner

`KeySizeFeedback` stores only request_id/state/message. The controls at lines 111-128 compare only the shared request sequence, while the controller retains feedback when selecting another supported row/key in the same board. A failed or saved A resize is therefore displayed under B until another request increments the sequence; selection change does not clear it. Qualify feedback with the originating scope/context/selection and filter by the displayed owner while preserving exact operation settlement. Add a production mounted/controller regression for A failure or completion followed by B selection.
