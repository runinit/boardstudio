## Required corrections

1. **P2 — Retained callbacks revive after selection/workspace ABA.** `presentation.rs:1004–1043` validates the scope, snapshot token/revision and current selected part, but its `context_generation` is passed `layout_owner.generation` at the Editor projection. `current_layout_owner` assigns that generation directly from `SelectionAdapter.generation`, which App increments only for scope changes (`presentation.rs:235–239`). Selecting A→B→A, or leaving Layout and returning with the same accepted snapshot/scope, restores every captured predicate. An old A action can again mutate A or navigate to PCB after its original Inspector owner has retired. The generation names do not establish separate selection/view ownership. Use a production owner lifetime or monotonic context/view generation that retires on these transitions; reject retained actions after unmount. Cover same-snapshot selection and workspace ABA through the actual production callback path, with an expected-red control.

2. **P2 — Part edge margin keyboard editing is incomplete.** The input's Enter handler at `inspector/layout_component_inspector.rs:442` only prevents default; its commit exists exclusively in `onblur`. Typing a margin and pressing Enter therefore leaves the accepted outline unchanged. Pinned `OutlineInspector.tsx::Dimension` explicitly blurs on Enter (committing valid input) and restores the accepted value on Escape; the new input does neither. Share the valid margin commit/reset behavior between blur and keyboard handlers or invoke actual blur, and verify mounted Enter/Escape behavior including invalid finite/nonnegative input.

3. **P2 — Production edit/owner wiring is untested.** All three `layout_component_inspector_tests.rs` WASM tests construct a `ReadModel` and call `layout_component_inspector_projection`; they cover metadata, rejection and Relations precedence only. None mounts `LayoutComponentInspector`, exercises form events, runs `layout_component_inspector_owner_is_current`, or invokes the Editor action handler/Runtime edit route. The inventory accurately limits their claims, but these helpers do not qualify the new mutating production route. Add bounded mounted coverage using the same production handler/owner seam for position, assignment, outline and constraint actions, current-owner rejection and PCB navigation. Full integrated visual/history/save-reopen acceptance remains separate; it is not being demanded as a prerequisite for source review.
