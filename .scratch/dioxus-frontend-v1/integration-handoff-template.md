# Ready packet handoff

Use [frontend delivery records](../../docs/agents/issue-tracker.md#frontend-delivery-records).
One message linking the frozen commit and existing receipt is sufficient:

- Parent/packet ID and retained final joins.
- Isolated worktree, commit and owned source paths.
- Existing spec/ticket and React fixture/journey reference.
- Checks actually run, changed outcome and unresolved limits.
- Any new RF evidence, or a scoped no-new-finding note in the receipt.

The coordinator owns shared integration, the live queue, the combined check/package,
and parent status. Authors keep one waiting packet per stream. Sol reviews the
frozen integrated candidate once; changed callback/identity/API behavior is included
in that review. Targeted repairs reuse unchanged evidence. Parent acceptance decisions
reference the finalized candidate review and their criterion accounting.

Build manifests and source/asset hashes remain packaging evidence. They are linked
from the live record rather than copied into each author handoff. Historical detailed
handoffs remain valid evidence for the source they assessed.
