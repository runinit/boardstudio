# M1 presentation interaction browser evidence

This is focused development-candidate evidence, not complete M1 acceptance. The latest root/subpath development page built from integration source `736ca94fe5f273dfb4cd6b2919580ad34a9fc4d5` is staged under `web/target/builds/interactions-integrated-736ca94/`, served at `http://127.0.0.1:4325/` and `http://127.0.0.1:4325/boardstudio/`. Both page WASM files have SHA-256 `36b66d4e97c6e27b6b78e88d9a7c76ce1011a17854fe373bff62c3550b5187b9`. The dev stage omits generated `service-worker.js`: registration returned 404, and neither path had a controlling service worker. This avoids service-worker cache mixing; the release worker build remains unverified here.

Earlier focused interaction stages were built from the same presentation source changes before the later root-only CAD/session merges:

- `interactions-fix-5bc93a45`, page WASM `0ffd9d43c37470160ec130125b83bb155803a71bdc7fbe344cc54812afa6b2f3`, exposed the Escape failure with `#m1-position-x` focused and native bubbling `keydown` confirmed.
- `interactions-merged-ed036a77`, page WASM `bb95b7891ab8326b1530def4b0f857537a7517b96c140da2a910e5c4b00a4cb0`, validated pointer thresholds, cancellation and history after merging the session CAD reconciliation.
- `interactions-a11y-ed036a77`, page WASM `bd0afe27c0169dd5e9cab10ce374a84a326d8367cfb8c6317a4d6874bf26758b`, validated empty-selection keyboard entry and compact layout after the tab-stop fix.

The Escape failure was repaired by using Dioxus `KeyboardData` and `event.prevent_default()` directly; cancellation now takes the draft out of its `RefCell` before submitting its restore. On the rebuilt page, changing X from 147.285 to 155 showed preview-only status; Escape restored X/Y to 147.285/-51.02 and cleared preview status. Changing X to 150 and pressing Enter committed, displayed `Saved locally.`, and added a saved-library button without a reload. The browser reported no page errors.

Pointer checks on REVIUNG41 confirmed a 2 px movement did not change the part transform; a 25 px drag committed a final transform. Undo restored the starting transform and Redo reapplied it. Escape after passing the drag threshold reported `Cancelled.` and did not commit the in-flight preview after pointer-up. On Sofle Left PCB, a scripted native PointerEvent with a 5 px/2 px Alt drag moved from `(9.18,-78.048)` to `(11.0143,-78.7817)` without snapping; Undo restored the start. The same delta without Alt snapped to `(8.83,-77.958)`. Shift-click on `matrix/left-keys/r0c5` from `r0c0` selected the 11-part visible range; Ctrl-click removed that endpoint (10 selected) and a second Ctrl-click restored it (11 selected). These scripted modifier events exercise the browser event handlers but are not hardware-input testing.

The initial empty-selection list regression was reproduced on REVIUNG41: all options had `tabindex=-1`. With the first-option fallback, a fresh REVIUNG41 open at 920x500 had no selected option and `#m1-component-0` had `tabindex=0`. Tab navigation reached that component after the editor controls; ArrowDown moved focus and selection to `#m1-component-1`. At 920x500, Sofle had no horizontal document overflow (920 px width), editor canvas was 700x350, and the page remained vertically scrollable to reach later controls. The compact screenshot is [`sofle-920x500.png`](sofle-920x500.png).
