# F7.3f: Deliver archive-backed imported-board models through Case

**Parent:** F7.3 — Single shared assembly viewer and model-preview adapter.

**What to build:** When a user opens a project with an enabled imported/routed board reference in Case, show its real STEP/STP, STL, and WRL models in the shared viewer, preserve their board placement, and let a picked model select only its currently mapped board part. Missing or invalid models report their own recoverable status while healthy models remain visible.

**Blocked by:** F7.1 is the only canonical start prerequisite. F7.3g (generated-board preview delivery) reuses the private model-delivery provider established here. INT.2 and BND.1 remain F7.3 acceptance joins, not start blockers. This draft is not dispatchable until the corrected private-port contract and this ticket receive independent clearance.

**Acceptance joins (not start blockers):** Existing Case issue 02 remains the integration-acceptance join for the combined viewer and model-delivery path. The canonical F7.3 joins remain INT.2 and BND.1, and F7.8 remains the later cross-workflow join. This child does not close issue 02, F7.3, or any parent.

**Author-owned boundary:** Own the isolated private Case model-delivery component and its focused tests. Root owns the Runtime/CoreWorker `PreviewBoard` producer port (BoardReference asset ID→document Asset SHA→verified board bytes→current-batch artifact request), verified model-byte/STEP ports, private page-host decode forwarding and source-sync delta, Case/shared-viewer registration and scene integration, and CSS/build changes. Preserve reusable `web/src/renderer_host.rs`; only the private page host snapshot/extensions are changed. Land shared ports serially through the root. Do not edit the public library host/API, renderer exports, Core schema, document format, or asset-provider visibility.

Unsupported extensions, bad bytes, decoder failures, and missing assets produce scoped per-model feedback rather than fabricated geometry.
