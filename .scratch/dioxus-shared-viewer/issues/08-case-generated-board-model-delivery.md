# F7.3g: Deliver models from generated board previews through Case

**Parent:** F7.3 — Single shared assembly viewer and model-preview adapter.

**What to build:** In Case, show real document-backed models belonging to a generated Ergogen board preview. Prepare the preview from the accepted-provenance effective physical Case document and contours projected from its current `CadScene`; run the existing Kicad/Ergogen conversion privately, finish it through Core’s existing validator, resolve model assets to verified archive/document bytes, and attach decoded meshes to their exact model rows in the shared viewer. The generated worker must work at the public root and `/boardstudio/` routes and after offline installation. Unarchived `ergogen:model:*` static bytes are deferred: the cleared archive-byte contract does not include a bundled static provider.

The corrected KiCad bridge proposal and this issue have independent Spec/Standards clearance.

**Acceptance joins (not start blockers):** Existing Case issue 02 remains the integration-acceptance join for combining this producer with imported-board models, Case projection, viewer lifecycle and public route behavior. Keep canonical F7.3 `acceptance_after: [INT.2, BND.1]` and later F7.8 unchanged. This child does not close issue 02 or any parent.
