# F7.3f: Deliver archive-backed imported-board models through Case

**Parent:** F7.3 — Single shared assembly viewer and model-preview adapter.

**What to build:** When a user opens a project with an enabled imported/routed board reference in Case, show its real STEP/STP, STL, and WRL models in the shared viewer, preserve their board placement, and let a picked model select only its currently mapped board part. Own the one private verified-byte/model-delivery lifecycle reused by native preview consumers: bind pending, partial, failed, and delivered rows to the accepted Case preview owner, which exists before mechanical Case CAD. Missing or invalid models report their own recoverable status while healthy models remain visible.

**Blocked by:** F7.1 is the only canonical start prerequisite. Issue 08 (generated-board preview delivery) reuses the private model-delivery provider established here as an implementation handoff only. INT.2 and BND.1 remain F7.3 acceptance joins, not start blockers.

**Acceptance joins (not start blockers):** Existing Case issue 02 remains the integration-acceptance join for the combined viewer and model-delivery path. The canonical F7.3 joins remain INT.2 and BND.1, and F7.8 remains the later cross-workflow join. This child does not close issue 02, F7.3, or any parent.

**Author-owned boundary:** Own the isolated private Case model-delivery component and its focused tests. The provider owner is an immutable preview-source identity comprising the selected `Scope`, accepted snapshot token/revision, mounted viewer/projection generation, and preview batch. It must not require a generated mechanical `CadScene` or use `Weak<CadScene>` as the only source-liveness guard. The page owner validates that the captured Case source still matches Runtime's accepted document and selected physical instance before and after provider work. Root owns the Runtime/CoreWorker `PreviewBoard` producer port (BoardReference asset ID→document Asset SHA→verified board bytes→current-batch artifact request), native Prepare/Finish preview source, verified model-byte/STEP ports, private page-host decode forwarding and source-sync delta, Case/shared-viewer registration and scene integration, and CSS/build changes. Preserve reusable `web/src/renderer_host.rs`; only the private page host snapshot/extensions are changed. Land shared ports serially through the root. Do not edit the public library host/API, renderer exports, Core schema, document format, or asset-provider visibility.
