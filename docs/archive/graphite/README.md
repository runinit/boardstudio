# Historical Graphite Node runners

These files preserve the former `scripts/test-graphite-feedback.cjs` and
`scripts/test-graphite-usability.cjs` source for historical evidence. They are
not supported commands and their original relative paths no longer apply.
Use `python3 scripts/run-graphite-feedback.py` or
`python3 scripts/run-graphite-usability.py` for the current manual checks.
