# Keymap workspace

Use BoardStudio's existing engineering workbench and selected light/dark theme, typography, accent, inspector sections and compact controls. Keymap owns logical behavior; Keycaps owns physical profiles, legends, colors, fit and STEP export. The layer list precedes the selected-key editor. Select geometry, choose a behavior, then edit only its applicable parameters. Search the keycode palette without obscuring the selected key. Macros and encoders have named structured editors. Empty states explain how to add physical inputs or layers. Local Rust edits and ZMK source export are authoritative; no keyboard connection is implied.

DYA and ZMK are interaction references only; no source is copied. Preserve existing keycap settings and legacy base bindings. Persist layer identifiers rather than layer indices. Resolve indices only at export. Finding navigation uses exact diagnostic locations when available and truthful object geometry otherwise.

Verification uses public Rust edit/export APIs and browser workflows, including Undo, switching workspaces, layer references, macro and encoder exports, and located outline warnings. Review desktop and narrow viewport states with real labels and populated data.
