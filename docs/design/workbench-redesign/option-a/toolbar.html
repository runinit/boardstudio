Toolbar: 42px, open or closed

Click Select, Transform, Align, Snap, or View. The chosen section slides open inside the same strip; its neighbours fold down to icons. Click it again, click the canvas, or press Escape to fold it away. Action names appear wherever the available space allows; narrower sections fall back to icons with accessible names and hover hints. The strip never gains a second row.

Where all the controls went

Select: Matrix, Row, Column, Key, Part. Changing scope never opens another popup.

Transform: Column → Stagger, Spread, Offset, Splay, Origin. Row → Offset, Shift, Bend. Key → Shift, Bend. Matrix → Move, Rotate, Anchor when anchored. Independent part → Move, Rotate, Anchor; anchored parts also have Spread and Stagger. First-column Spread and locked/unsupported actions stay unavailable.

Align: six edge/centre actions slide into the strip. Its settings control opens Reference part and Relationships.

Snap: all eight increments, Geometry snap, and Envelope gap. Its settings control reveals the gap override and explanatory text.

View: Keys, Components, Keycaps, Footprints, Board, Canvas handles. The active tool retains the handle it needs.

Position icon: reveals exact values without reserving an Inspector pane. In production, it should focus the existing Inspector, not introduce a second editing owner.

Unchanged: camera controls remain in the footer; project actions, history, workspace navigation, and document creation stay outside this tool strip. Existing Alt / Shift / Ctrl gesture modifiers remain contextual hints.

Disposable presentation mockup. No project data is edited, saved, or exported. Drawing and values are illustrative; manipulation gestures are not implemented here.
