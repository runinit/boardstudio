## Approved validation seams

1. **Real application workflows and mounted composition:** real Session/Core Runtime,
   controlled effects and actual disposable storage for storage-specific crossings.
2. **Source-bound packaged-page journeys:** trusted keyboard input, genuine supported
   context-loss/reopen and a real two-release offline transition.
3. **Accepted source to actual package round-trip:** one supported assembly plus
   mixed-source assets, with project/PCB/firmware package consistency and notices.
