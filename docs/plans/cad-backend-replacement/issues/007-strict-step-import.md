**Identity and mapping contract.** Piece ID, loop ID and change `sequence` each use a separate namespace `(input_face_index, monotonically assigned ordinal)` local to this **one report**. They are not STEP entity IDs, stable cross-import IDs or interchangeable namespaces; the owner never reuses an ordinal after rollback. `pieces()`/`loops()` on a change return ordered `(BEFORE, AFTER)` groups for that single mutation, including every split child and join parent. Shell-level iterators enumerate surviving records; a reference to a discarded/missing record fails capture completeness. These getters consume no caller IDs and confer no authority on a tuple constructed elsewhere.

`source_use = (input_face_index, original_boundary_index, original_edge_use_offset)` indexes the exact borrowed input shell before `oriented_edge_indices` reverses traversal. `native_interval = (shared_edge_index, (t_start,t_end))` retains that input edge's **whole finite native domain**, directed by this use, before sampling/restriction; the shared edge must equal the edge at `source_use`. Importer-owned face/loop/edge bindings translate these indices to original STEP IDs. `domains` returns the full directed `(UV, XYZ)` intervals in the current piece's respective actual parameter frames; those frames may differ from one another and from the native frame. Generated pole/bridge pieces may have no unique native edge/use; they retain their actual parents and support/loop context instead of inventing one.
